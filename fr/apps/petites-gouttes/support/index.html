Petites Gouttes. Support

Pour une question sur cette app, utilisez Contact. Le message part de votre application mail.

La page de support de l'app est liée ci-dessous.

https://bnjdpn.com/petites-gouttes/#contact

Le formulaire est protégé contre le spam par Cloudflare Turnstile, qui analyse des signaux techniques du navigateur (dont l'adresse IP) pour distinguer une personne d'un robot. Turnstile n'est chargé que sur la page de l'app qui contient le formulaire de contact, pas sur ces pages. Le message est ensuite transmis par Cloudflare (Workers et Email Routing) à la boîte d'assistance du développeur, petites@bnjdpn.com. Les messages reçus sont lus et traités par un assistant automatisé (IA) utilisé par l'éditeur pour les trier et préparer ou envoyer les réponses ; l'éditeur reste responsable de ce traitement.
