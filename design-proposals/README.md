# Décision

Benjamin a choisi la direction B, Sommaire, le 8 octobre 2026.

Le catalogue public suit cette direction. Les noms sont en Bricolage Grotesque. Sur un grand écran avec survol, une seule capture reste à droite du sommaire. Sur un écran étroit, ou sans survol, la capture se place sous le nom. La fiche d'une app reprend la même affiche : le nom en grand, la capture à côté, puis dessous quand la place manque.

Les prototypes A (Chambre noire) et C (Établi), les maquettes de Sommaire et leurs captures ont été retirés. Les pages servies viennent du générateur.

Le bouton Contact assemble l'adresse au clic. Sans JavaScript, le texte renvoie vers la page de support déjà publiée pour chaque app, sans écrire l'adresse.
